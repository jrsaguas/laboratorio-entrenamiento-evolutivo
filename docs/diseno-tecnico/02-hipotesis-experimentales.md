# 02 — Hipótesis experimentales

**Versión:** 0.1 | **Estado:** inicial

Toda hipótesis debe especificar intervención, baseline, dataset, métricas, presupuesto y criterio de decisión.

Hipótesis iniciales:
- herramientas deterministas pueden mejorar la exactitud matemática;
- datos sintéticos filtrados por verificadores pueden mejorar capacidades concretas;
- recuperación selectiva puede ser más eficiente que contexto indiscriminado;
- técnicas eficientes pueden conservar rendimiento con menor coste.

Cada resultado debe distinguir evidencia de interpretación.
