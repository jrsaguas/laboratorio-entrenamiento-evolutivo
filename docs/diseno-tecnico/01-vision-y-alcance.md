# 01 — Visión y alcance

**Versión:** 0.1 | **Estado:** inicial

Crear un laboratorio donde un modelo y el sistema que lo rodea puedan evolucionar mediante experimentos medibles.

Incluye modelos abiertos, entrenamiento/post-entrenamiento, inferencia, agentes, herramientas, RAG, búsqueda, documentos, evaluación, recompensas y generación de datos.

No se pretende inicialmente entrenar un modelo fundacional desde cero a escala industrial.

**Pregunta central:** ¿qué combinación de modelo, datos, entrenamiento, herramientas y agentes produce la mayor mejora verificable con recursos limitados?
