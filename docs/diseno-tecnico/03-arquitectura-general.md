# 03 — Arquitectura general

**Versión:** 0.1 | **Estado:** inicial

Capas:
1. modelo: pesos, tokenizer y arquitectura;
2. inferencia: runtime, cuantización y serving;
3. agente: planificación, ejecución y control;
4. herramientas: código, CAS, búsqueda, archivos y validadores;
5. recuperación: índices, ranking y evidencia;
6. evaluación: benchmarks y verificadores;
7. laboratorio: datasets, experimentos, checkpoints y trazabilidad.

Las capas deben poder evaluarse por separado para atribuir efectos.
